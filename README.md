# Dashboard 
Modern and responsive dashboard built with the use of semantic HTML and CSS grid

## Key features :pushpin:
* CSS Grid layout
* Accessibility components
* Performance optimization
* Smooth transitions on hover states
* Fully responsive design (Mobile and Desktop)

## Performance and accessibility :mega:
This project implements best practices in terms of core web vitals and user-friendly design 

The following tools were used to measure it :
* [Google Lighthouse](https://developer.chrome.com/docs/lighthouse?hl=fr)
* [Wave of WebAIM](https://wave.webaim.org/)
